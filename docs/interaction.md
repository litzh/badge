# 设备交互

适用于 `badge-0.7.0`，不包含 HTTP 接口。

## 对话优先

主页显示时间、联网/电量、语音阶段和 BOOT 操作提示。IP、SSID、配网和调试信息移至设置/设备信息页。
当前使用内置 ASCII 字体：`READY`（就绪）、`LISTENING`（录音）、`RECOGNIZING`（识别）、
`THINKING`（思考）、`PREPARING AUDIO`（合成/下载）、`SPEAKING`（播放）、`TRY AGAIN`（失败）。
录音时显示秒数，失败时显示可读原因；完整错误码可在 Info 页查看。

| 操作 | 行为 |
| --- | --- |
| BOOT 短按，空闲时 | 唤醒回到主页，并开始录音 |
| BOOT 短按，录音时 | 结束录音并提交问题 |
| BOOT 短按，识别/思考/播放时 | 取消当前轮，不开始下一轮 |
| BOOT 持续按住 | 只触发一次，不重复操作，也不再开启配网；上电时已按住则等待松开后重新按下 |
| PWR 短按 | 亮屏时熄屏；屏保或熄屏时唤醒回到主页；不修改亮度、不取消问答 |
| PWR 长按 | 保留 AXP2101 硬件电源行为 |
| 屏保/熄屏时触摸 | 首次手势只唤醒回到主页，不触发其下方按钮 |
| 主页对话按钮 | 与 BOOT 相同，随状态显示 `Start talking` / `Send question` / `Cancel` |
| Settings | 打开设置页 |
| 设置页 Volume `-` / `+` | 每次减/加 10，范围 0–100，0 静音；播放中可调整，重启保留 |
| 设置页 Brightness `-` / `+` | 64 / 160 / 255 三档，重启保留 |
| 设置页 Wi-Fi setup | 开启蓝牙配网并显示设备信息；问答繁忙时禁用，避免干扰网络请求 |
| 设置页 Info / Back | 查看设备信息／返回上一级 |

所有可触摸按钮都有圆角边框和底色，点击区域与显示形状一致，最小高度 48 像素。
按下立即高亮，松开时执行；滑出按钮后即取消本次手势，滑回也不执行。
禁用/到达上下限的按钮置灰；音量和亮度修改后显示保存结果，失败保留原值。
按钮高亮短暂保留约 160ms 以便看清，不阻塞主循环；没有滑动翻页、双击或触屏长按动作。

## 待机与手动熄屏

空闲 10 秒进入粒子屏保，再持续最多 5 分钟后熄屏。低电时空闲 10 秒直接熄屏。
问答进行中保持已经亮起的屏幕唤醒，结束后重新计时。
用户按 PWR 熄屏后，录音/处理/播放可以继续，阶段变化和任务完成均不会自动亮屏。
BOOT、PWR 或新的触摸手势可以主动唤醒；HTTP 显式交互仍保留其原有唤醒行为。

开机恢复保存亮度，未保存时默认 160。屏保取正常亮度与 128 的较小值，
低电时不超过 64；不会覆盖保存设置。

## 屏保交互

80 个粒子共同响应声音、重力/旋转和温度：

| 输入 | 画面反应 |
| --- | --- |
| 声音大小、低中高频能量 | 改变亮度、运动强度和轨道起伏 |
| 倾斜 | 粒子群向倾斜方向偏移 |
| 绕屏幕法线转动 | 改变旋流方向和速度 |
| 轻摇 | 粒子短暂散开再聚拢 |
| IMU 芯片温度变化 | 缓慢改变整体色调，不代表环境温度 |

声音和动作不会唤醒状态页；安静、静止时画面仍缓慢运动。
屏保采样不保存、不上传；主动发起的语音问答会保存本轮录音到 PSRAM 并调用云端。
语音问答期间暂停屏保采音；手动熄屏优先于问答保持亮屏，见 [语音问答](voice.md)。
熄屏保持 Wi-Fi 在线，不能把熄屏等同于深度睡眠或整机关机。
持续低电压会单独触发保护关机；关机后触摸不能唤醒，需要接电源或使用硬件电源键。
电量提示和保护条件见 [电池管理](power-management.md)。
算法、资源占用和验证记录见 [visualizer.md](visualizer.md)。

## Wi-Fi 与蓝牙配网

- 开机优先使用 NVS 保存的网络，其次使用固件内置的默认网络。
- 没有配置，或连接在约 20 秒窗口内仍未成功时，开放蓝牙配网。
- 在 Settings 点击 Wi-Fi setup 可手动开放配网，使用项目 `web/provision.html` 连接 `BADGE-xxxx`。
- 提交网络配置会唤醒并重新计时；连接成功后才保存新配置，失败不覆盖原配置。
- 新配置连接并保存成功后停止配网广播；运行中 Wi-Fi 断开会尝试重新连接。

## USB 串口调试

115200 波特率，每条命令以换行结束：

| 命令 | 行为 |
| --- | --- |
| `status` | 输出状态，不唤醒屏幕 |
| `scan` | 未在连接网络时执行扫描，不重置待机计时；同步扫描可能暂时影响动画 |
| `provision` | 唤醒并开启蓝牙配网 |
