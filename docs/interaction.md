# 设备交互

适用于 `badge-0.6.0`，不包含 HTTP 接口。

## 状态切换

开机显示状态页；最后一次交互后 10 秒进入粒子屏保；屏保最多显示 5 分钟后熄屏。
触摸或按键可以从屏保或熄屏状态唤醒，并重新计时。
状态页显示连接状态、Wi-Fi 名称、IP、电量估计、电压、充电/低电提示、触摸坐标和配网提示，
只刷新变化的文字行。充电/低电提示占用原触摸坐标行。
状态页底部有语音录音/取消入口；没有滑动翻页或双击动作。

| 操作 | 行为 |
| --- | --- |
| 触摸屏幕 | 唤醒、更新触摸坐标、重新开始 10 秒计时 |
| 状态页底部语音区域 | 空闲时开始录音，录音时结束提交，处理或播放时取消；屏保/熄屏的首次触摸仅唤醒 |
| 状态页 `Volume` 两侧 `[-]` / `[+]` | 每次减/加 10，范围 0–100，0 静音；播放中也可调整，重启保留 |
| BOOT 短按 | 唤醒并重新计时 |
| BOOT 长按 3 秒 | 开启蓝牙配网；按住期间保持唤醒 |
| PWR 短按 | 唤醒并循环切换亮度：64 → 160 → 255 → 64；设置保存到 NVS |
| PWR 长按 | 由 AXP2101 硬件处理电源控制，固件没有定义额外长按动作 |
| 10 秒无交互 | 进入粒子屏保、启动麦克风采样 |
| 屏保持续 5 分钟 | 面板休眠，停止采音和动画；Wi-Fi、电池查询继续运行 |
| 低电模式下 10 秒无交互 | 跳过屏保直接熄屏；已在屏保则停止动画并熄屏 |

开机恢复保存亮度，未保存时默认 160。屏保使用正常亮度与 128 的较小值，
唤醒后恢复原亮度并停止采音。屏保亮度不会覆盖保存设置。

## 屏保交互

80 个粒子共同响应声音、重力/旋转和温度：

| 输入 | 画面反应 |
| --- | --- |
| 声音大小、低中高频能量 | 改变亮度、运动强度和轨道起伏 |
| 倾斜 | 粒子群向倾斜方向偏移 |
| 绕屏幕法线转动 | 改变旋流方向和速度 |
| 轻摇 | 粒子短暂散开再聚拢 |
| IMU 芯片温度变化 | 缓慢改变整体色调，不代表环境温度 |

声音和动作不会唤醒状态页；安静、静止时画面仍缓慢运动。
屏保采样不保存、不上传；主动发起的语音问答会保存本轮录音到 PSRAM 并调用云端。
语音问答期间暂停屏保采音和待机计时，完成后恢复，见 [语音问答](voice.md)。
熄屏保持 Wi-Fi 在线，不能把熄屏等同于深度睡眠或整机关机。
持续低电压会单独触发保护关机；关机后触摸不能唤醒，需要接电源或使用硬件电源键。
电量提示和保护条件见 [电池管理](power-management.md)。
算法、资源占用和验证记录见 [visualizer.md](visualizer.md)。

## Wi-Fi 与蓝牙配网

- 开机优先使用 NVS 保存的网络，其次使用固件内置的默认网络。
- 没有配置，或连接在约 20 秒窗口内仍未成功时，开放蓝牙配网。
- 长按 BOOT 3 秒可手动开放配网，使用项目 `web/provision.html` 连接 `BADGE-xxxx`。
- 提交网络配置会唤醒并重新计时；连接成功后才保存新配置，失败不覆盖原配置。
- 新配置连接并保存成功后停止配网广播；运行中 Wi-Fi 断开会尝试重新连接。

## USB 串口调试

115200 波特率，每条命令以换行结束：

| 命令 | 行为 |
| --- | --- |
| `status` | 输出状态，不唤醒屏幕 |
| `scan` | 未在连接网络时执行扫描，不重置待机计时；同步扫描可能暂时影响动画 |
| `provision` | 唤醒并开启蓝牙配网 |
