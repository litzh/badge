# 设备交互

适用于 `badge-0.4.2`，不包含 HTTP 接口。

## 状态切换

开机显示状态页；最后一次交互后 10 秒进入粒子屏保；触摸或按键唤醒状态页并重新计时。
状态页显示连接状态、Wi-Fi 名称、IP、电池电压、触摸坐标和配网提示，只刷新变化的文字行。
当前没有触摸菜单、滑动翻页或双击动作。

| 操作 | 行为 |
| --- | --- |
| 触摸屏幕 | 唤醒、更新触摸坐标、重新开始 10 秒计时 |
| BOOT 短按 | 唤醒并重新计时 |
| BOOT 长按 3 秒 | 开启蓝牙配网；按住期间保持唤醒 |
| PWR 短按 | 唤醒并循环切换亮度：64 → 160 → 255 → 64；设置保存到 NVS |
| PWR 长按 | 由 AXP2101 硬件处理电源控制，固件没有定义额外长按动作 |
| 10 秒无交互 | 进入粒子屏保、启动麦克风采样 |

开机恢复保存亮度，未保存时默认 160。屏保使用正常亮度与 128 的较小值，
唤醒后恢复原亮度并停止采音。屏保亮度不会覆盖保存设置。

## 屏保交互

80 个粒子共同响应声音、重力/旋转和温度：

| 输入 | 画面反应 |
| --- | --- |
| 声音大小、低中高频能量 | 改变亮度、运动强度和轨道起伏 |
| 倾斜 | 粒子群向倾斜方向偏移 |
| 绕屏幕法线转动 | 改变旋流方向和速度 |
| 轻摇 | 粒子短暂散开再聚拢 |
| IMU 芯片温度变化 | 缓慢改变整体色调，不代表环境温度 |

声音和动作不会唤醒状态页；安静、静止时画面仍缓慢运动。
原始音频不保存、不上传，当前没有语音聊天或扬声器播放功能。
屏保保持 Wi-Fi 在线，不是自动关机、关屏或深度睡眠。
算法、资源占用和验证记录见 [visualizer.md](visualizer.md)。

## Wi-Fi 与蓝牙配网

- 开机优先使用 NVS 保存的网络，其次使用固件内置的默认网络。
- 没有配置，或连接在约 20 秒窗口内仍未成功时，开放蓝牙配网。
- 长按 BOOT 3 秒可手动开放配网，使用项目 `web/provision.html` 连接 `BADGE-xxxx`。
- 提交网络配置会唤醒并重新计时；连接成功后才保存新配置，失败不覆盖原配置。
- 新配置连接并保存成功后停止配网广播；运行中 Wi-Fi 断开会尝试重新连接。

## USB 串口调试

115200 波特率，每条命令以换行结束：

| 命令 | 行为 |
| --- | --- |
| `status` | 输出状态，不唤醒屏幕 |
| `scan` | 未在连接网络时执行扫描，不重置待机计时；同步扫描可能暂时影响动画 |
| `provision` | 唤醒并开启蓝牙配网 |
